# fred plugins
This is the official repo containing community-created and fred author-created plugins.

## Modal plugins
* Vim mode - `vim/vim-mode.h`.
  * To install, copy the header file to disk and add `#include "vim-mode.h"` to the bottom of your plugin file.  The path can also be a relative directory leading to `vim-mode.h`.
